📚 The Complete Git Cheat-Sheet Directory

6 Roadmap phases ke saari major aur minor commands ka systematic dynamic control.

Phase 1: Basics Local
git init

Ek bilkul naya, empty local repository create karne ke liye.

git init
Phase 1: Basics Config
git config --global

Aapka commit identity name aur developer email configure karne ke liye.

git config --global user.name "Aditya"
Phase 1: Basics Staging
git add

Files ko uncommitted local states se Staging Area me bhejne ke liye.

git add .
Phase 1: Basics Local History
git commit -m

Staged changes ko unique custom message ke sath permanent save point dene ke liye.

git commit -m "Message"
Phase 2: Branching Parallel universe
git branch

Nayi branches banana aur existing local active branch list check karne ke liye.

git branch feature-styles
Phase 2: Branching Branch switch
git switch

Kisi doosri active branch ke code universe me shift karne ke liye.

git switch feature-styles
Phase 2: Branching Merge
git merge

Kisi specific feature branch ka finished code apni primary branch me merge karne ke liye.

git merge feature-styles
Phase 3: Conflicts Remote Fetch
git fetch

Server se naya changes download karna local computer ke current code ko chhede bina.

git fetch upstream
Phase 4: Advanced Soft rollback
git reset --soft

Committed history mita dena bina aapka physical files ka code delete kiye.

git reset --soft HEAD~1
Phase 4: Advanced Destructive
git reset --hard

WARNING! commits aur aapke machine se files ka code dono hamesha ke liye saaf karne ke liye.

git reset --hard <commit_id>
Phase 4: Advanced Code Locker
git stash

Incomplete/Half code ko safety se ek temporary locker space me chupane ke liye.

git stash
Phase 4: Advanced Locker pop
git stash pop

Locker box se aakhiri safe-keep code wapas nikal kar branch par paste karne ke liye.

git stash pop
Phase 4: Advanced Pick single
git cherry-pick

Kisi doosri branch ka ek specific perfect commit copy karke apni active branch me milaana.

git cherry-pick <id>
Phase 5: Open Source Fork sync
git remote add upstream

Original project jahan se fork kiya tha use upstream remote nickname se add karne ke liye.

git remote add upstream <URL>
Phase 6: Automation CI/CD YAML
GitHub Workflows CI

Automatic code integration pipelines set karne ke liye workflow folder design.

.github/workflows/ci.yml
